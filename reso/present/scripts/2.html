💻 IP itu seperti nomor telepon perangkat

Alamat IP (Internet Protocol) itu seperti nomor telepon untuk perangkat-perangkat kita.

Jadi kalau toiletku mau kirim pesan ke jam tanganku,

ia bisa melakukannya karena mereka punya “nomor” untuk saling komunikasi.

Tapi bukan nomor telepon beneran — mereka pakai alamat IP.

Tanpa alamat IP, perangkat-perangkat itu gak bisa saling ngobrol.

Karena itu, setiap perangkat kita punya satu alamat IP agar bisa berkomunikasi

dan juga terhubung ke internet.

Setiap perangkat yang kamu pakai untuk nonton video gmeet ini juga punya alamat IP.

Itu karena perangkatmu lagi ngobrol sama Google — kirim dan terima data.

Kita bisa lihat alamat IP kita sendiri dengan langkah-langkah berikut:

  • Di Windows:
    • Buka CMD (Command Prompt)
    • Ketik perintah: ipconfig
    • Tekan Enter
    • Kamu akan melihat tulisan seperti: IPv4 Address : 192.168.1.10
  • Di Linux:
    • Buka terminal
    • Ketik perintah: ifconfig
  • Di HP:
    • Buka pengaturan Wi-Fi
    • Pilih jaringan yang sedang terhubung
    • Lihat informasi jaringan — di situ akan terlihat alamat IP-nya

Jangan bingung dengan “V4”-nya dulu — nanti kita bahas.

Sekarang, lihat alamat IP ini:

Tampak aneh kan? Deretan angka dipisahkan titik — kayak kode rahasia.

Tapi di sampingnya ada dua teman baiknya: Subnet Mask dan Default Gateway.

  • Subnet Mask (kadang disebut Netmask)
  • Default Gateway (alias Router)

Keduanya penting banget buat bikin alamat IP “hidup”.

🌐 Dari mana asal alamat IP-mu?

Siapa yang kasih? Aman nggak?

Jawabannya:

Kalau kamu pakai Wi-Fi di rumah atau kantor,

yang ngasih alamat IP adalah router kamu.

Router itu seperti Pak RT dari dunia jaringan:

Router membagikan alamat IP lewat sebuah proses ajaib bernama DHCP (Dynamic Host Configuration Protocol).

Sekarang kamu mungkin sadar,

kok hampir semua alamat IP lokal dimulai dengan 192.168.1.x?

Itu karena si “Pak RT” alias router sudah mengatur subnet seperti itu lewat Subnet Mask.

Subnet Mask biasanya terlihat seperti ini:

255.255.255.0

Dan ini adalah hack penting yang harus kamu tahu:

Kalau di subnet mask ada angka 255,

itu berarti bagian IP tersebut tidak berubah untuk semua perangkat di jaringanmu.

Jadi:

192.168.1 adalah network portion (bagian jaringan) — tetap sama untuk semua perangkat

Angka terakhir (.x) adalah host portion (bagian perangkat) — bisa berubah dari 1 sampai 254

Makanya kamu bisa punya alamat seperti:

192.168.1.10 (laptop)

192.168.1.20 (HP)

192.168.1.30 (printer)

dan seterusnya.

🌍 Apa Itu Subnet Mask?

Oke, jadi… subnet mask — Inilah cara kita membentuk jaringan di seluruh dunia. Di sinilah keajaiban subnetting terjadi. ✨

Makanya setiap IP address — bahkan IP address kamu — selalu punya subnet mask. Dan subnet mask ini menyimpan sebagian besar rahasia tentang jaringanmu.

tugas utama si Subnet Mask ini adalah untuk memberi tahu kita seberapa besar jaringan kita, berapa banyak IP address yang tersedia, dan lain-lain.

Dan kamu mungkin juga masih ingat trik kecil kita waktu itu: kalau kita lihat 255 di subnet mask, itu berarti octet yang bersesuaian di IP address kita itu “beku” — nggak bisa diubah, nggak akan berubah, tetap seperti itu selamanya.

Tapi pertanyaannya: kenapa 255 bisa bikin angka itu nggak berubah? Apa sebenarnya yang terjadi di balik layar? Kenapa 255 itu istimewa banget? Apa sih yang dilakukan subnet mask? Kenapa nilainya harus 255?

Nah, di sesi ini kita bakal bongkar kap mesinnya. 🧠🔧 Kita bakal lihat apa sih yang sebenarnya terjadi, kenapa subnet mask bekerja seperti itu, dan kenapa dia penting banget.

Ini IP address saya — dan ini versi binary-nya — kode Matrix penuh 1 dan 0. ini sudah kita pelajari di sesi sebelumnya.

Tapi satu hal yang belum kita lakukan waktu itu: Kita belum ubah subnet mask ke binary. Dan ya, kita bisa banget melakukannya sekarang. Dan ini bakal lebih gampang dari yang kamu kira.

Contoh, ambil octet pertama: 255. Kita mau tahu bit pertamanya ON atau OFF. Bisa nggak kita kurangi 128 dari 255? Jawabannya: bisa banget. Berarti bit pertama = ON (1).

Sekarang 255 - 128 = 127. Lanjut: bisa nggak 127 dikurangi 64? Bisa. Bit kedua juga ON. 127 - 64 = 63. 63 - 32 = 31 → ON lagi.

Dan spoiler alert ⚡ semua bit di sini bakal ON semua. Karena kalau kamu tambahkan semua nilai binary: 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1 = 255.

Itu artinya, 255 = semua bit hidup. Keren kan?

Sekarang, coba lihat subnet mask lengkapnya: 255.255.255.0 Kalau kita ubah ke binary: semua bit ON di tiga octet pertama, dan semua bit OFF di octet terakhir. Karena 0 = semua bit mati. Gampang banget.

Nah, ini bagian paling keren dan penting. Inilah alasan kenapa kita repot-repot ubah ke binary.

Karena bit-bit 1 dan 0 itu sebenarnya “ngomong” ke kita. Mereka berbisik tentang rahasia jaringan. 🕵️‍♂️ “Dengar baik-baik…”

Bit yang 1 (ON) bilang, 👉 “Ini bagian network dari IP address.” Dan bit yang 0 (OFF) bilang, 👉 “Ini bagian host dari IP address.”

Jadi lihat subnet mask kita ini. Tiga octet pertama = semua bit 1 → network bits. Octet terakhir = semua bit 0 → host bits. Host bits inilah yang bisa berubah, yang dipakai buat ngasih alamat IP ke device-device di jaringanmu.

Sekarang, berapa banyak host bisa kita punya? Cukup hitung jumlah bit 0. Di sini ada 8 bit 0 (satu octet penuh).

Gunakan rumus sakti: 2ⁿ - 2 dimana n = jumlah bit 0.

Jadi: 2⁸ = 256 → 256 - 2 = 254 usable IP address. Kenapa dikurang 2? Karena satu buat network address, dan satu buat broadcast address.

Tapi… gimana kalau kamu butuh lebih banyak IP? Misalnya 500 host dalam satu jaringan?

Jawabannya: kita butuh lebih banyak 0 alias lebih banyak host bits. Caranya? Kita “curi” 1 bit dari network side, dan ubah jadi host bit. Kayak Robin Hood versi subnetting. 😎

Sekarang kita punya 9 bit host. 2⁹ - 2 = 510 usable IP address! Boom! 🎉 Itu dia, kamu baru aja melakukan subnetting.

Subnetting pada dasarnya cuma mengubah subnet mask buat nyesuaiin kebutuhan kita.

Dari 255.255.255.0, karena kita ubah 1 bit jadi host, nilai barunya jadi 255.255.254.0. Keren kan?

Dan satu hal penting: Subnet mask itu selalu contiguous — artinya, bit 1-nya selalu berurutan, nggak bakal ada “1 1 1 0 1”. Itu nggak boleh terjadi. Harus semua 1 dulu, baru semua 0. Selalu dalam blok utuh.

5 + 1 + 2 + 2 + 20 = 30 host

kita bulatkan jadi 40 host per coffee shop.

Jadi — kita butuh 40 alamat IP (host) untuk tiap jaringan.

🔍 Langkah 1 — Berpikir Berbeda

Kalau sebelumnya kita subnet berdasarkan berapa banyak jaringan yang dibutuhkan,

kali ini kita subnet berdasarkan berapa banyak host yang kita perlukan di tiap jaringan.

Kedua cara ini hampir sama, tapi ada satu perbedaan besar.

📐 Subnet Mask Awal

Sekarang subnet mask kita:

255.255.255.0 (karena /24).

Dan seperti biasa, ini yang bakal kita “otak-atik” buat bikin jaringan-jaringan baru kita.

Tapi sebelum itu, kita harus ubah dulu ke binary.

💡 Subnet Mask dalam Binary:

11111111.11111111.11111111.00000000

Sekarang kita udah punya subnet mask dalam kode Matrix.

Dan dari sini, kita bisa mulai alokasikan bit-bit buat subnet berdasarkan jumlah host.

🧠 Langkah 2 — Hitung Bit Host

Kita butuh 40 alamat IP.

Kita lihat di tabel:

32 → kurang

64 → pas banget ✅

Jadi, kita butuh 64 total alamat untuk menampung 40 host (dengan sisa untuk network & broadcast).

Sekarang, berapa banyak bit host yang dibutuhkan buat nyampe ke angka 64?

1, 2, 3, 4, 5, 6 → 6 bit host. ✅

⚙️ Langkah 3 — Hack (atau Simpan) Bit

Nah, biasanya kalau kita subnet berdasarkan network, kita “hack” bit host dari kiri ke kanan.

Tapi kali ini, karena subnetting-nya berdasarkan host.

Kita flip caranya.

Sekarang kita nyimpen bit host, mulai dari kanan ke kiri.

Kita butuh 6 bit host → simpan 6 bit di kanan.

Sisa bit di kiri? Nah, itu yang bakal jadi network bits baru.

Artinya subnet mask kita berubah — lebih besar nilai network-nya, lebih sedikit ruang buat host.

⚙️ Langkah 4 — Tentuin Increment

Increment = nilai dari bit jaringan terakhir (network bit terakhir).

Kalau kita lihat, bit ke-7 di octet terakhir adalah 1,

yang nilainya 64 (128, 64, 32, 16, 8, 4, 2, 1 — kamu tahu daftarnya).

Jadi increment = 64.

🔢 Langkah 4 — Alokasi Subnet

Kita mulai dari: 192.168.1.0

Increment kita = 64

Jadi subnet-nya:

192.168.1.0 - 192.168.1.63

192.168.1.64 - 192.168.1.127

192.168.1.128 - 192.168.1.191

Boom 💥

Tiga jaringan untuk tiga coffee shop.

Masing-masing punya 64 total IP (62 usable).

Pas banget buat kebutuhan 40 host. ✅

🧩 Subnet Mask Baru & CIDR

Sekarang kita konversi kembali ke decimal.

Kita tahu:

255.255.255.???

Octet terakhirnya?

Binary-nya 11000000.

128 + 64 = 192

Jadi subnet mask barunya:

👉 255.255.255.192

atau dalam notasi CIDR: /26
